# OTOSAN FARM — Website

Website giới thiệu thương hiệu OTOSAN FARM (Fine Robusta Việt Nam), song ngữ Việt – Nhật.

## Cấu trúc thư mục

```
otosan-farm-website/
├── index.html      ← Trang web chính (mở file này để xem)
└── assets/         ← Toàn bộ ảnh và logo
```

## Cách xem thử trên máy tính

Chỉ cần bấm đúp vào file `index.html`, trình duyệt sẽ mở lên và hiển thị website.

## Cách đưa lên GitHub (không cần biết lập trình)

1. Vào https://github.com → đăng nhập → bấm nút **New** (tạo repository mới).
2. Đặt tên, ví dụ: `otosan-farm-website` → chọn **Public** → bấm **Create repository**.
3. Trong trang repository vừa tạo, bấm **uploading an existing file** (hoặc **Add file → Upload files**).
4. Kéo thả toàn bộ **cả 2 mục**: file `index.html` và **cả thư mục `assets`** vào ô upload
   (nếu GitHub không cho kéo thả nguyên thư mục, kéo từng file bên trong `assets/` vào, miễn giữ đúng tên thư mục `assets`).
5. Bấm **Commit changes**.

## Cách để website hiển thị công khai qua một đường link (GitHub Pages) — miễn phí

1. Trong repository, vào **Settings → Pages**.
2. Ở mục **Source**, chọn nhánh `main`, thư mục `/ (root)` → **Save**.
3. Đợi khoảng 1–2 phút, GitHub sẽ cấp một đường link dạng:
   `https://<tên-tài-khoản>.github.io/otosan-farm-website/`
4. Đây là link chị có thể gửi cho khách hàng hoặc đối tác Nhật Bản xem trực tiếp, không cần cài gì thêm.

## Lưu ý khi cập nhật nội dung sau này

- Muốn sửa chữ, giá, thông tin liên hệ → mở `index.html` bằng bất kỳ trình soạn thảo text nào (Notepad, VS Code...), tìm đúng đoạn chữ tiếng Việt cần sửa.
- Muốn thêm/đổi ảnh → thêm file ảnh mới vào thư mục `assets/`, rồi sửa tên file tương ứng trong `index.html`.
- Nếu không quen thao tác này, gửi lại yêu cầu cho Claude kèm nội dung cần đổi, Claude sẽ chỉnh trực tiếp trong file rồi gửi lại bản mới.
